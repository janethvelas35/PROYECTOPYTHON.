# Sudoku Python

Una versión sencilla de un juego de Sudoku desarrollada en Python. Este proyecto está pensado como una base para practicar lógica, estructuras de datos, validación de reglas y programación de interfaces de consola.

## Descripción

El juego permite al usuario completar un tablero de 9x9 siguiendo las reglas clásicas del Sudoku:

- Cada fila debe contener los números del 1 al 9 sin repetir.
- Cada columna debe contener los números del 1 al 9 sin repetir.
- Cada subcuadrícula 3x3 debe contener los números del 1 al 9 sin repetir.
- El jugador puede ingresar números en casillas vacías y verificar si el tablero es válido.

## Funcionalidades

- Tablero de Sudoku generado o precargado.
- Validación de movimientos.
- Verificación de victoria.
- Interfaz por consola simple.
- Fácil de extender con nuevas funciones.

## Requisitos

- Python 3.8 o superior.
- Terminal o consola compatible con texto.

## Cómo ejecutar

1. Abre una terminal en la carpeta del proyecto.
2. Ejecuta el archivo principal:

```bash
python proyecto1.py
```
